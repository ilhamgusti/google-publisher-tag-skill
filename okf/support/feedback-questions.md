# Feedback and questions

To ensure your feedback and questions are routed correctly, follow
the links and instructions on this page.

| I have feedback or questions about... ||
|---|---|
| Google Ad Manager | First, review the [Ad Manager help center documentation](https://support.google.com/admanager/). If you still have feedback or questions: - Post to the [Ad Manager help community](https://support.google.com/admanager/community/). - Contact [Ad Manager customer support](https://support.google.com/admanager/gethelp). |
| Google Publisher Tag | |---|---| | Documentation | Use the **Send feedback** button located near the top of the page on which you'd like to provide feedback. > [!IMPORTANT] > **Important:** We are unable to respond to feedback submitted using the **Send feedback** button. | | Samples | Use the **Report an issue** button located near the bottom of the page on which you'd like to provide feedback. <br /> **OR** Open an issue in the [Google Publisher Tag code sample GitHub repository.](https://github.com/googleads/google-publisher-tag-samples) | | TypeScript type definitions | Open an issue in the [Google Publisher Tag type definitions GitHub repository.](https://github.com/googleads/google-publisher-tag-types) | | Everything else | - Post to the [Ad Manager help community](https://support.google.com/admanager/community/). - Contact [Ad Manager customer support](https://support.google.com/admanager/gethelp). | |
