## Overview

The GPT sample builder is a tool for creating custom,
interactive GPT test pages. These test pages are referred to as
samples.

Samples are configured through the settings panel. This panel separates
GPT configuration options into the following sections:

- **Page settings**: where you configure general options that control how GPT behaves across all ad requests.
- **Slot settings**: where you configure one or more ads to display and set slot-specific options. You can choose from a selection of example ads, or provide custom values to display ads from your own Google Ad Manager account.
- **Output settings**: where you configure the output of the tool.

Learn more about the available page- and slot-level configuration options in
the [GPT Reference](https://developers.google.com/publisher-tag/reference).

> [!NOTE]
> **Note:** The GPT sample builder is a work in progress. Not all GPT features and configuration options are supported at this time.
