# Samples

Implementation samples with runnable JavaScript and TypeScript code:

- [Ad Event Listeners](./ad-event-listeners.md) - Sample listening to slotRenderEnded, impressionViewable, and slotVisibilityChanged.
- [Ad Sizes Sample](./ad-sizes.md) - Sample implementation using sizeMapping to support responsive ad slots.
- [Basic Concepts Sample](./basic-concepts.md) - Sample demonstration of core GPT ad slot definition and rendering.
- [Collapse Empty Ad Slots](./collapse-empty-ad-slots.md) - Sample showing how to collapse unfilled ad slots automatically.
- [Configure Privacy Settings](./configure-privacy.md) - Sample configuring CCPA (RDP), GDPR (TFUA), and COPPA privacy compliance.
- [Control SRA Batching](./control-sra-batching.md) - Sample implementation demonstrating how to control SRA batching.
- [Display Anchor Ad](./display-anchor-ad.md) - Sample implementing sticky top or bottom anchor ads for mobile and desktop.
- [Display Gaming Interstitial Ad](./display-gaming-interstitial-ad.md) - Sample implementing gaming interstitial ad experiences.
- [Display Limited Ads](./display-limited-ad.md) - Sample implementing limited ads mode when cookie/personalization consent is absent.
- [Display Out-of-Page Ad](./display-out-of-page-ad.md) - Sample demonstrating generic out-of-page ad unit definition.
- [Display Rewarded Ad](./display-rewarded-ad.md) - Sample implementing rewarded ads where users view ads for in-app rewards.
- [Display Side Rail Ad](./display-side-rail-ad.md) - Sample implementing left and right side rail display ads.
- [Display Test Ad](./display-test-ad.md) - Sample implementation showing how to display a test ad from Google's test network.
- [Display Web Interstitial Ad](./display-web-interstitial-ad.md) - Sample implementing full-screen interstitial ads between page navigations.
- [Event-Based Ad Requests](./event-based-requests.md) - Sample demonstrating requesting ads triggered by specific user interactions.
- [Infinite Content / Scroll](./infinite-content.md) - Sample showing lazy loading and dynamic ad slot injection for infinite scroll.
- [GPT React / Next.js Integration](./integrations/react.md) - Guide and sample for integrating GPT into React and Next.js applications.
- [Key-Value Targeting Sample](./key-value-targeting.md) - Sample demonstrating page-level and slot-level targeting keys and values.
- [Lazy Loading Ads](./lazy-loading.md) - Sample showing viewport-based ad request pausing and lazy rendering.
- [Offerwall Custom Choice](./offerwall-custom-choice.md) - Sample demonstrating publisher-customized choices inside Google Offerwall.
- [Refresh Ad Slots](./refresh.md) - Sample implementation showing how to refresh specific ad slots dynamically.
- [Reserve Space (Anti-CLS)](./reserve-space.md) - Sample demonstrating slot space reservation to prevent Cumulative Layout Shift.
- [Shadow DOM Integration](./shadow-dom.md) - Sample showing how to render GPT ads inside Shadow DOM boundaries.
